# منوی کافه دانه · Daneh Coffee House

منوی تعاملی فارسی با طراحی راست‌به‌چپ، الهام‌گرفته از تخته‌شاسی و منوی کاغذی تصویر مرجع. پیاده‌سازی با React، TypeScript و Vite است. فونت و تصاویر از داخل پروژه بارگذاری می‌شوند و به CDN وابسته نیستند.

## اجرا

Node.js 22.12 یا جدیدتر:

```sh
npm ci
npm run dev
```

```sh
npm test         # تست‌های منو، سبد و رسید
npm run build    # بررسی TypeScript و ساخت dist/
npm run preview  # پیش‌نمایش خروجی نهایی
```

## رابط کاربری و حرکت

- منو تمام‌عرض است: منوی کاغذی با دو جدول کنار هم، و «ویژه‌های دانه» به شکل ردیف‌های افقی بزرگ با تصویر، توضیح، قیمت و دکمهٔ افزودن. کارت‌های بغل حذف شده‌اند.
- کامپوننت‌های `src/components/ui` با الگوی shadcn/ui و Radix ساخته شده‌اند (`button`, `badge`, `input`, `separator`, `toggle`, `toggle-group`). پیکربندی در `components.json` و توکن‌های رنگ در `@theme` داخل `src/styles.css` است. دستور `npx shadcn add <component>` هم آماده است.
- انیمیشن‌ها با GSAP انجام می‌شوند: ورود هیرو با `SplitText`، پارالاکس با `ScrollTrigger`، گذار فیلترها با `Flip`، افکت مغناطیسی دکمه‌ها و کاسکید پنل سفارش (`src/hooks/motion.ts`). در حالت `prefers-reduced-motion` همه غیرفعال می‌شوند.

## سفارش

- نوشیدنی را با جست‌وجو یا دسته‌بندی پیدا کنید. در منوی کاغذی، نام و دکمهٔ مثبت جزئیات را باز می‌کنند؛ انتخاب قیمت، اندازهٔ مربوط به همان ستون را نیز انتخاب می‌کند.
- در پنل سمت چپ اندازه و تعداد را مشخص کنید. قیمت واحد زیر نام و در سمت چپ نمایش داده می‌شود؛ توضیحات ۵۰ پیکسل پایین‌تر قرار دارد.
- از دکمهٔ «سفارش من» در بالای سمت چپ، تعدادها را ویرایش کنید، آیتمی را حذف کنید، یا سفارش را تأیید کنید.
- سبد و آخرین رسید در `localStorage` همان مرورگر نگهداری می‌شوند. رسید برای نشان دادن به باریستاست؛ این نسخه سفارش را به سرور ارسال نمی‌کند و درگاه پرداخت ندارد.

## فایل‌های اصلی

- `src/menu.ts`: نام‌ها، ترکیبات، توضیحات، اندازه‌ها و قیمت‌ها (به تومان). جدول کاغذی قیمت را به **هزار تومان** نمایش می‌دهد.
- `src/order.ts`: بازیابی و اعتبارسنجی سبد و ذخیرهٔ رسید.
- `src/components/Menu.tsx`: منوی کاغذی، کارت‌ها، فیلترها و جست‌وجو.
- `src/components/Drawer.tsx` و `Order.tsx`: پنل کشویی و مراحل سفارش. پنل از دیالوگ بومی مرورگر برای مدیریت فوکوس و کلید Escape استفاده می‌کند.
- `src/styles.css`: رنگ‌ها، چیدمان واکنش‌گرا، انیمیشن‌های هاور و کلیک و حالت کاهش حرکت.
- `public/assets`: تصاویر بهینه‌شدهٔ WebP، بافت کاغذ و فونت Estedad. مجوز فونت در `public/assets/fonts/OFL.txt` قرار دارد.
